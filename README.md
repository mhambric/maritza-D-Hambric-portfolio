# Maritza Hambric Portfolio

This repository contains the source code for my personal portfolio website. The site showcases my work across computer science, UX research, and web development, with a focus on user centered, research informed digital products.

The portfolio was designed and built from scratch using HTML, CSS, and JavaScript and is deployed as a static site.

---

## About the Portfolio

This portfolio highlights my interdisciplinary background and skill set, including:

- Frontend web development
- UX research and interaction design
- Database driven thinking and system design
- Research informed product decisions

The site includes a featured case study, an interactive prototype, and supporting pages that describe my background, skills, and experience.

---

## Featured Case Study

### StudyBuddy
A UX research and design project focused on helping online students connect with nearby classmates to form study groups, build accountability, and reduce isolation.

The case study includes:
- Project overview and problem framing
- User research and survey insights
- Wireframes and high fidelity prototypes
- Interactive prototype demonstrating core user flows
- Key learnings and next steps

An interactive Figma prototype is embedded to demonstrate navigation patterns and user flow.

## Project Structure

This repository contains only frontend code and static assets.

Typical structure:
- `index.html` – Home page
- `about.html` – About me and skills
- `studybuddy.html` – Case study
- `prototype.html` – Interactive prototype page
- `contact.html` – Contact form
- `styles.css` – Global styles
- `images/` – Project images and assets

Backend code and database driven projects are maintained in separate repositories.

---

## Deployment

The portfolio is deployed as a static site using Netlify.

No server or backend is required to run this project locally or in production.

---

## Local Development

To run the site locally:
1. Clone the repository
2. Open `index.html` in a browser  
   or  
   Use a simple local server such as Live Server in VS Code
