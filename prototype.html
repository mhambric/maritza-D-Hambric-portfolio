StudyBuddy Prototype

Interactive prototype demonstrating core user flows

Try the Prototype

This interactive prototype showcases the core navigation and user flow of the StudyBuddy application.

  • Navigate between Home, Discovery Friend Finder, Messages, and Profile
  • Explore how users discover classmates and return to the home feed
  • Review interaction patterns and information architecture

This prototype focuses on validating user flow and design intent rather than full system functionality.

Tip: Use the top navigation icons to explore different sections of the app. Content creation via the plus icon, are intentionally excluded to keep the prototype focused on navigation clarity and flow validation.
