Featured Live Web App

Student PeerNest

A full stack web application that helps online, commuter, and nontraditional students connect

Student PeerNest is a live React and Express application. The app includes a public homepage, About page, demo login, Discovery dashboard, Feed, Messenger, and Profile pages. I built the frontend with React, Vite, React Router, custom CSS, React Icons, and Google Fonts, and I deployed the project through Vercel.

This project shows my ability to move from research and design into a working web application. It also demonstrates responsive design, routing, frontend styling, backend communication, deployment, accessibility considerations, and product planning.
